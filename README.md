# Project Management System

A simple project management system for beginners, built with JavaScript.

## Overview

This project is designed to help beginners learn project management concepts and implement them in a simple, user-friendly web application. It provides essential features for organizing tasks, managing projects, and tracking progress.

## Features

- ✅ **Task Management** - Create, edit, and delete tasks
- ✅ **Project Organization** - Organize tasks into different projects
- ✅ **Status Tracking** - Track task status (To Do, In Progress, Completed)
- ✅ **User-Friendly Interface** - Simple and intuitive UI for easy navigation
- ✅ **Local Storage** - Save your projects and tasks locally
- ✅ **Responsive Design** - Works on desktop and mobile devices
